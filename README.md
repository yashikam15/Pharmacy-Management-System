# 💊 Pharmacy Management System

A web-based Pharmacy Management System developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB. This application helps pharmacists manage medicine inventory efficiently by providing CRUD (Create, Read, Update, Delete) operations along with stock and expiry monitoring.

---

## 📌 Features

- ➕ Add new medicines
- 📋 View all medicines
- ✏️ Update medicine details
- ❌ Delete medicines
- 🔍 Search medicines
- 📦 Stock monitoring
- 📅 Expiry date monitoring
- 💾 Data storage using MongoDB

## 🚀 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/yashikam15/Pharmacy-Management-System.git
```

2. Open the project folder

```bash
cd Pharmacy-Management-System
```

3. Install dependencies

```bash
npm install
```

4. Start the server

```bash
node server.js
```

5. Open your browser and visit

```
http://localhost:3000
```
